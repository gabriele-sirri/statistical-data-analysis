# Optional material

Self-study modules. They are **not** part of the four labs and not assessed.
Each notebook runs from the `optional/` folder (paths are relative).

| Notebook | Topic | Use it for |
|---|---|---|
| `tmva_magic_demo.ipynb` | BDT with TMVA on MAGIC data; efficiency, rejection, purity; Asimov significance and the optimal cut | the MAGIC project case; vocabulary translation ML ↔ physics |
| `rdf_cpp_speed.ipynb` | Python loop vs RDataFrame (C++ JIT) vs multithreading | understand why modern C++ matters |
| `convolution_resolution.ipynb` | Breit–Wigner ⊗ Gaussian with `RooFFTConvPdf` | resolution models (Lab 1, B1) |
| `upper_limit_cls.ipynb` | CL$_s$ upper limit with RooStats | CUORE-0, dark-matter-like searches |

Slides for the TMVA demo: `../slides/optional_tmva.md`.

Every notebook ends with questions. No solutions are provided: they are open exercises, ask in class.
