# github.com/gabriele-sirri/statistical-data-analysis

**Welcome!** Open the course page and choose **one** way to run ROOT / RooFit.

**On your computer**
conda · precompiled ROOT binaries · Windows binaries · WSL (Ubuntu inside Windows) · your package manager

**In the cloud (nothing to install)**
GitHub Codespaces (requires a GitHub account) · SWAN · Binder

The course uses mainly **Jupyter notebooks**, but you can run **C++ macros** as well: if you know C++ and not Python, you are fine.

Installation guides: `docs/` · then check: `python course/tools/check_setup.py`
